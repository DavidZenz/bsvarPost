# bsvarPost: Posterior Analysis for bsvars and bsvarSIGNs

Posterior summaries, inference, model comparison, and visualisation for
Bayesian structural vector autoregressions estimated with the `bsvars`
and `bsvarSIGNs` packages.

## Result tables

Posterior tables include provenance as ordinary columns, alongside the
estimates and identifiers. See
[posterior_provenance](https://davidzenz.github.io/bsvarPost/reference/posterior_provenance.md)
for probability, scaling, units, software versions and draw-identity
definitions. Default reports and CSV exports include these columns;
compact reports omit most provenance columns. Select columns explicitly
when a fixed schema is needed.

## Vignettes

Use
[`utils::browseVignettes()`](https://rdrr.io/r/utils/browseVignettes.html)
to open the package articles:

- `browseVignettes(package = "bsvarPost")`

If no vignettes are listed there, reinstall the GitHub package with
`build_vignettes = TRUE`.

The package includes the following articles:

- Post-estimation Analysis with bsvarPost (`bsvarPost`)

- Inference and Comparison (`inference-and-comparison`)

- Historical Decompositions (`historical-decomposition-events`)

- Analysis of Sign-Restricted Models (`sign-restricted-workflows`)
